# Music Portal — Artist Discovery Website

Music Portal is a web application that helps users discover musicians and explore structured information about artists.

Users can search for musicians by year, genre, and region, view artist details, and learn more about biographies, albums, awards, and top tracks.

## Overview

The goal of this project was to create a music discovery platform where users can search for artists and explore detailed information in a clear and organized interface.

The project combines search and filtering functionality, dynamic data loading, artist detail pages, and account-related functionality such as registration and login.

## Features

- Musician search by year, genre, and region
- Artist detail pages
- Biography, genre, country, albums, awards, and top tracks
- Registration and login functionality
- Dynamic data loading
- Responsive layout for desktop, tablet, and mobile
- Bootstrap-based UI components
- Adaptive interface for different screen sizes

## Tech Stack
